# 📚 Recursos adicionales 🟢

[Lia Carrizo](https://training.lidr.co/members/21261563)

Aquí tienes una curaduría de herramientas y recursos recomendados para trabajar con bases de datos en proyectos reales. No es lectura obligatoria — son recursos a los que volver cuando los necesites en tu día a día.

## 🔒 Seguridad de bases de datos

**OWASP Database Security Cheat Sheet**

La referencia canónica de la industria para seguridad en bases de datos. Cubre cifrado, control de acceso, hardening y patrones seguros por tipo de motor. Si solo consultas un recurso de seguridad de DB, que sea este.

🔗 https://cheatsheetseries.owasp.org/cheatsheets/Database_Security_Cheat_Sheet.html

## 🗑 Soft Delete con Prisma

**Prisma Client Extensions — Query**

La forma idiomática actual de implementar soft delete en Prisma (v5+). Reemplaza al patrón de middleware, hoy deprecado. Documentación oficial con ejemplos listos para adaptar.

🔗 https://www.prisma.io/docs/orm/prisma-client/client-extensions/query

## 🤖 IA + Base de datos (con contexto real del esquema)

**Model Context Protocol — Servers oficiales**

Colección de servidores MCP que conectan tu base de datos directamente a Cursor, Claude Code o Claude Desktop. Tu IDE entiende el esquema real, genera queries sin alucinar tablas y puede analizar resultados de EXPLAIN ANALYZE sobre tu DB local. Incluye servidor para Postgres, SQLite y más.

🔗 https://github.com/modelcontextprotocol/servers

**Supabase MCP Server**

Equivalente para proyectos en Supabase. Acceso a esquema, migraciones y funciones directamente desde tu IDE con IA.

🔗 https://github.com/supabase-community/supabase-mcp

## 📊 Observabilidad y performance

**pg_stat_statements**

La extensión nativa de Postgres para análisis de queries. Gratis, incluida en cualquier instalación estándar. Es el primer lugar donde mirar cuando tu DB va lenta antes de pedirle ayuda a la IA.

🔗 https://www.postgresql.org/docs/current/pgstatstatements.html

**pganalyze**

Plataforma de monitoreo y optimización de Postgres en producción. Detecta queries lentas, índices faltantes y genera recomendaciones automáticas. Muy útil cuando tu equipo ya pasó la fase inicial.

🔗 https://pganalyze.com/

## 🛠 Cliente universal

**DBeaver Community Edition**

Cliente de base de datos universal (Postgres, MySQL, SQLite, MongoDB y muchos más). Gratis y open source. Las versiones recientes integran asistente IA para generar y explicar queries.

🔗 https://dbeaver.io/
