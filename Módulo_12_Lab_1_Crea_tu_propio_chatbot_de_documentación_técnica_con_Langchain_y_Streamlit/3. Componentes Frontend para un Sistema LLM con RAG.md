En esta sección exploraremos los componentes frontend para construir el sistema LLM con RAG. Nos centraremos en Streamlit, una herramienta poderosa y fácil de usar para crear aplicaciones web interactivas con Python. También revisaremos las alternativas relevantes en 2026: Chainlit, Gradio, Langflow y Open WebUI.

# 1. Streamlit (usado en el laboratorio)
Streamlit es una biblioteca de Python que permite crear aplicaciones web interactivas y visualmente atractivas con solo unas pocas líneas de código. Es ideal para prototipar y desplegar aplicaciones de IA y aprendizaje automático rápidamente.

## Características Clave de Streamlit
Simplicidad: permite crear aplicaciones web sin necesidad de conocimientos avanzados de desarrollo web. Basta con escribir Python y Streamlit se encarga del resto.

Interactividad: ofrece widgets interactivos (sliders, botones, formularios, file uploaders) que facilitan la creación de interfaces dinámicas.

Componentes nativos de chat: st.chat_message, st.chat_input y st.write_stream son APIs estables para construir interfaces conversacionales con streaming token a token.

Integración con Python: se integra perfectamente con bibliotecas populares (TensorFlow, PyTorch, Hugging Face, LangChain, LlamaIndex).

Despliegue fácil: Streamlit Community Cloud permite desplegar aplicaciones gratuitamente. Streamlit fue adquirido por Snowflake en 2022 y sigue siendo open-source y plenamente vigente.

## Implementación con Streamlit
Para nuestro sistema LLM con RAG utilizaremos Streamlit para crear una interfaz sencilla e intuitiva. Los usuarios podrán ingresar preguntas y recibir respuestas generadas por el modelo en tiempo real, así como añadir documentos para dar contexto al sistema.

# 2. Chainlit — alternativa específica para chat RAG
Chainlit es un framework Python diseñado específicamente para interfaces conversacionales de IA. Es la alternativa principal a Streamlit cuando el foco es chat con LLMs y agentes. Aunque no la usaremos en este laboratorio, conviene conocerla.

## Características Clave de Chainlit
Streaming nativo en tokens: sin hacks, viene de fábrica.

Visualización step-by-step del razonamiento del agente: muestra tool calls, retrieval steps y cadenas de procesamiento, ideal para depurar Agentic RAG.

Threads con histórico persistente y autenticación multi-proveedor (Okta, Azure AD, Google).

Recolección de feedback de usuario integrada (thumbs up/down con razonamiento).

Async-first: construido sobre asyncio, mejor rendimiento bajo carga.

Cuándo elegir Chainlit sobre Streamlit: si tu aplicación es exclusivamente chat con un agente y quieres mostrar los pasos intermedios al usuario (qué documentos recuperó, qué herramientas invocó), Chainlit es objetivamente mejor herramienta. Si necesitas también gráficos, dashboards o componentes no-chat, Streamlit gana por versatilidad.

Más información: chainlit.io.

# 3. Gradio
Gradio es otra herramienta popular para crear interfaces de usuario de modelos de aprendizaje automático. Ofrece una plataforma intuitiva para crear interfaces web interactivas y compartir modelos de IA con usuarios finales.

## Características Clave de Gradio
Facilidad de implementación: crea interfaces de usuario interactivas con muy poco código.

Interactividad: soporta texto, imágenes, audio y video como entradas y salidas.

Compartir fácilmente: integración nativa con Hugging Face Spaces (incluido el modo ZeroGPU para correr modelos sobre GPU H200 sin coste).

Versión 5.x: trajo mejoras significativas en rendimiento, custom CSS, custom React Components y temas.

Es la opción más adecuada para demos rápidas de un solo componente ("subo una imagen, el modelo me devuelve una predicción"). Para chat RAG completo, Streamlit y Chainlit dan más flexibilidad.

# 4. Langflow
Langflow es una herramienta visual que permite diseñar y construir pipelines de procesamiento de lenguaje natural mediante una interfaz gráfica de arrastrar y soltar. Aunque no la utilizaremos en este laboratorio, Langflow se ha convertido en una de las plataformas no-code/low-code más populares del ecosistema de IA.

## Características Clave de Langflow (2026)
Interfaz visual: crear y modificar pipelines de IA mediante arrastrar y soltar componentes (LLMs, retrievers, prompts, herramientas).

Compatibilidad amplia: soporta LangChain, OpenAI, Anthropic, Google, Hugging Face, Ollama y más.

Despliegue flexible: disponible como herramienta local, en DataStax Astra o autoalojado.

100.000+ estrellas en GitHub a inicios de 2026 (eran 49.000 en febrero 2025): una de las herramientas open source de IA con mayor crecimiento.

## Estado tras la adquisición DataStax → IBM
### Cronología verificada:

Abril 2024: Langflow es adquirido por DataStax.

25 febrero 2025: IBM anuncia la intención de adquirir DataStax (incluyendo Langflow) para integrarlo en el portfolio watsonx.

2025: cierre de la adquisición. Langflow queda oficialmente bajo IBM.

2026: Langflow está plenamente integrado en watsonx.data; AstraDB integra capacidades vectoriales en watsonx.data y Langflow funciona como middleware con watsonx Orchestrate. El equipo de Langflow ha pasado de <10 a 20+ ingenieros tras la adquisición.

Sigue siendo open-source bajo IBM y es una opción seria para prototipos enterprise integrables con el stack watsonx.

Más información: langflow.org.

# 5. Open WebUI
Open WebUI (anteriormente Ollama WebUI) es una interfaz web autoalojada para interactuar con LLMs locales (vía Ollama) o vía APIs compatibles con OpenAI. Se ha convertido en el front-end self-hosted estándar para "ChatGPT-like UI" sobre LLMs locales.

## Características Clave de Open WebUI
RAG con upload de documentos integrado (sin programar nada).

Soporte de imágenes y multimodal en modelos compatibles.

Web search integrado.

Soporte MCP para herramientas externas.

Gestión multi-usuario con RBAC, ideal para despliegues internos en una empresa.

Recomendación: si tu objetivo es "tener una UI de chat sobre Ollama lista en 5 minutos", Open WebUI es la respuesta. Para construir un RAG didácticamente desde cero (objetivo de este laboratorio), Streamlit es mejor opción porque escribes el flujo línea a línea y entiendes cada paso.

# 6. Otras alternativas a tener en el radar
Reflex (antes Pynecone): framework full-stack Python que compila a React. Vigente, comunidad creciente, curva más alta. Buena opción cuando Streamlit se queda corto y necesitas una app web "de verdad".

NiceGUI: lightweight, basado en Vue.js, popular para apps internas. Punto medio entre Streamlit y un framework web completo.

Mesop (Google): framework Python web con tracción moderada, muy por detrás de Streamlit/Gradio en adopción real.
